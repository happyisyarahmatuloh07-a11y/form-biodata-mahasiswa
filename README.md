# Form Biodata Mahasiswa

## Deskripsi

Form Biodata Mahasiswa adalah aplikasi sederhana berbasis HTML, CSS, dan JavaScript yang digunakan untuk menginput dan menampilkan data biodata mahasiswa.

Aplikasi ini dibuat untuk menerapkan konsep dasar pemrograman event-driven, validasi input, dan manipulasi tampilan menggunakan JavaScript.

## Fitur

- Input nama lengkap
- Input NIM
- Input program studi
- Input semester
- Input email
- Validasi input kosong
- Validasi NIM hanya berupa angka
- Validasi semester 1 sampai 14
- Validasi format email
- Tombol Simpan (menyimpan data ke array dan tabel)
- Tombol Bersihkan (mereset kolom input tanpa menghapus tabel)
- Reset input form otomatis setelah data berhasil disimpan
- Menampilkan daftar biodata mahasiswa dalam bentuk tabel responsif
- Mampu menyimpan banyak data (multi-data)

## Teknologi

- HTML
- CSS
- JavaScript
- Antigravity IDE

## Cara Menjalankan

1. Buka folder project di **Antigravity IDE**.
2. Buka file `index.html` langsung melalui browser pilihan Anda (klik dua kali file `index.html` atau klik kanan lalu buka di browser).
3. Isi data biodata pada form yang tersedia, lalu klik tombol **SIMPAN** untuk menambahkan data ke dalam tabel.
4. Gunakan tombol **BERSIHKAN** untuk mengosongkan kembali kolom input form.
